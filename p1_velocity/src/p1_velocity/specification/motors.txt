5. 抱闸、惯量及质量的处理方案

RH-17：brake_present=true [用户确认]。
brake_hold_torque、brake_release_voltage、brake_release_current、
brake_engage_delay、brake_release_delay、brake_initial_state：全部 TBD。
以上为实物参数的待核准状态；本模型的仿真初始状态按用户要求明确设为抱紧。
是否失电抱紧、是否允许动态制动、如何反馈已松闸：TBD。
35/54 N·m 是电机额定/峰值驱动力矩，不能代替抱闸保持力矩。
XML 用 brake_body_rear_fold、brake_body_front_fold 两条关节等式约束近似理想抱闸，active=true，默认抱紧。
XML 抱紧在 qpos0；find_angle.py 启动时更新保持角度为 TARGET_ANGLE 的初始实际姿态；B 同时切换两个 body_*_fold。
抱闸时记录当前实际角度，约束保持该角度，并禁用这两个电机的执行器组，驱动力矩置零；
对应原生 Control 滑块变灰不可调，每轮仍恢复锁定目标，避免遗留指令。
松闸时重新启用滑块，并以当时实际角度重设目标和过渡参考；Backspace 复位后重新抱紧初始角度，身体滑块禁用。
直接通过 API 松开两闸时，设 data.eq_active[brake_ids]=False，并清除 model.opt.disableactuator 的 (1<<1) 位以启用 group 1 的 RH-17 电机。
再次抱紧前设 model.eq_data[brake_ids,0]=当前角度-model.qpos0[对应qposadr]，然后启用约束并禁用 group 1。
约束保持精度受仿真求解器影响；实际保持力矩、动作延迟与电气行为尚未标定。
54 N·m 只限制电机驱动力矩，不是抱闸保持能力。抱闸约束力不计入电机力矩标签。

RH-17 表中转动惯量分 N/B 两行，但未注明参考轴，也未解释 N/B 含义。
如果确认 B 为带抱闸版本且该惯量是输入转子侧，才讨论按减速比平方折算：
J_joint = J_rotor × N² [W1]；不能在轴侧不明时直接填 armature。
DM6248P、DM4340P、M3508 的转子惯量均未由本次资料给出。
damping、frictionloss、减速器效率、间隙刚度和电机响应延迟均为 TBD。
现有模型中零阻尼/零附加惯量只是当前假设，不能把它们标记为实测电机参数。

电机整机质量仅记录用于后续核对，不直接叠加到现有 link 质量。
现有质量已包含相应 CAD 零件及人工标定；若实物型号发生改变，应按归属重新核算，
不能把整台电机质量都加在轮子转动 link 上，也不能重复加入已计入的手臂电机。

10. 实际控制仍需要补齐的参数

以下项目不会由“填写力矩和 rpm”自动得到：
  - 实物配置：各类电机完整版本、实际供电、额外机械传动；M3508 电调已确认 C620。
  - 关节标定：每个 joint 的电机方向、编码器零位、减速器输出与 joint 的对应。
  - 运动边界：实测机械角度限位、轮速/加速度目标、允许电机峰值时长及恢复条件。
  - 通信：每台电机 ID、CAN 总线分组与实际波特率、报文定义、单位和字节序。
  - 反馈：位置/速度/电流的轴侧与比例、单圈展开、采样率、延迟与丢包处理。
  - 闭环：控制周期、MIT/位置/速度环 Kp/Ki/Kd、增益单位、积分限幅和启停逻辑。
  - 电气：相电流与母线电流定义、Kt/Ke 口径、母线限流、回生/制动约束。
  - 动态：转子惯量、摩擦/阻尼、减速器效率、间隙、弹性及真实力矩响应。
  - 保护：过流/过温/欠压/过压的实际配置、故障反馈、复位和通信超时动作。
  - 抱闸：RH-17 保持力矩、供电、释放/抱紧时间、初始状态和状态反馈。

优先请用户核对：
  1) 21 个关节映射及手部 DM-J4340P-2EC V1.1 是否对应实物。
  2) DM6248P、DM4340P 分别用 24V 还是 48V，以及实际母线配置。
  3) 峰值允许时长、热降额条件；M3508 的 4.5 N·m 为堵转资料，非厂家峰值额定。
  4) DM6248P 的 115rpm 电压标注、DM4340P 的相电阻和过流保护值。
  5) RH-17 抱闸参数及 N/B 行含义；输出端到关节是否还有额外传动。

11. find_angle.py 简易调姿用法

在项目目录、已安装 MuJoCo 的环境中运行：python model_evaluation/find_angle.py。
文件开头 TARGET_ANGLE 是 17 个电机的初始站姿角度表，单位 °，相对 CAD 零位；
TARGET_RPM 是 4 个 wheel_spin 的初始轮速表，单位 rpm，默认全部为 0。
初始站姿在内存模型中经过仿真检查；本轮未覆盖原始模型或生成脚本。
PD 的四组元组依次为 Kp、Kd、力矩上限 N·m、额定转速 rpm：
  body  = (400.0, 10.0, 54.0, 25.0)
  leg   = (200.0,  4.0, 97.0, 40.0)
  arm   = ( 40.0,  0.3, 40.0, 36.0)
  wheel = ( 0.15,  0.0,  4.5, 469.0)
上述增益用于仿真调姿，不是附件给出的实机驱动器增益。
角度 PD 按 rad、rad/s 计算；车轮采用速度 P 环（D=0），内部单位为 rad/s。
右侧展开 Control，通过滑块或数值输入调整目标；会绕过 PD 直接改物理状态的 Joint 滑块已隐藏。
Control 显示目标角度 ° / 轮速 rpm；画面左上角显示单位、按键和抱闸状态。
21 个电机的力矩标签随可见关节位置显示，以引线指向关节锚点，约 30 Hz 更新。
数值取实际 data.actuator_force，当前 gear=1，单位 N·m；不包含抱闸约束力。
|力矩| 不超过额定值时为白色，超过时为红色：body 35、leg 30、arm 12、wheel 3 N·m。
红色只表示超过连续额定力矩，不改变上表已经采用的峰值/堵转力矩限幅。
按住 Up：前进，左轮目标为 +DRIVE_RPM、右轮为 -DRIVE_RPM；按住 Down：后退，符号相反。
松开方向键或窗口失去焦点后，按键驾驶的四轮目标归零，由控制器制动，实际速度不会瞬间清零。
DRIVE_RPM 当前为 100 rpm，可调整前进/后退速度；未使用方向键驾驶时仍可手动调节各轮 Control 目标。
B：同时松开/抱紧两个身体折叠关节（启动时默认抱紧）；抱闸时保持当前实际角度，对应 Control 滑块变灰不可调。
松闸后从当时实际角度继续控制，不追踪抱闸期间的旧目标；具体近似方式见第 5 节。
Backspace：恢复完整初始站姿，包括车体位置和姿态、主动关节及四杆随动关节；
同时清零速度、外力和求解器历史，恢复初始角度目标、联动比较缓存及 PD 过渡参考；
四轮目标归零，两个抱闸重新抱紧初始角度，对应身体 Control 滑块保持禁用。
这是一次完整仿真复位，不靠大力矩从当前姿态拉回，因此不会带入复位前的动量。
四个轮速目标可分别调节；左右轮的 joint 轴相反，相同物理滚动方向需相反 rpm 符号。
前腿和后腿各自的 hip_swing、thigh_pitch、knee_motor 共六对左右关节双向联动：
修改任意一侧目标，另一侧同步为相反角度，匹配当前模型的镜像关节轴。
例如 right_front_knee_motor 改为 -90°，left_front_knee_motor 自动变为 +90°，反向修改也有效。
这是关节目标镜像，不是车体姿态反馈平衡；目标不合适或受到外力时仍可能倾倒。
